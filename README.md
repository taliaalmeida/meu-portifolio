## `01 // PROJECT_OVERVIEW`

> Portfólio pessoal desenvolvido por **Natalia Almeida** durante minha trajetória de formação em Tecnologia da Informação.

Este projeto reúne uma apresentação pessoal, projetos desenvolvidos e formas de contato em uma interface web responsiva e objetiva.

O objetivo é apresentar minha evolução prática em desenvolvimento web e transformar aprendizados em projetos reais.

---

## `02 // ABOUT_PROJECT`

### ✦ Sobre

O projeto foi desenvolvido como uma das primeiras aplicações da minha jornada em desenvolvimento web, com foco na construção de uma interface simples, organizada e funcional.

### ✦ Seções

- **Sobre mim** — apresentação e trajetória
- **Projetos** — trabalhos desenvolvidos durante os estudos
- **Contato** — canais para conexão profissional

## `04 // INTERFACE`

A aplicação utiliza **HTML5** para estruturação do conteúdo e **CSS3 com Flexbox** para organização e responsividade da interface.

O projeto mantém uma proposta visual limpa e direta, priorizando a apresentação do conteúdo e a navegação entre as seções.

---

## `05 // COMO_USAR`

### Execução local

```bash
git clone https://github.com/taliaalmeida/meu-portifolio.git
cd meu-portifolio
```

Abra o arquivo `index.html` no navegador.

### GitHub Pages

O projeto pode ser publicado utilizando o GitHub Pages, tendo o `index.html` como ponto de entrada da aplicação.
